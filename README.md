LabyrinthMakers
Labyrinth Game
===

# 

# &#x09;Description:



# This is a simple console-based labyrinth game written in C++. The player must find the exit while avoiding walls and collecting a key to unlock the door.

# 

# &#x09;Features:



# \- Randomly generated labyrinth.

# \- Choose labyrinth size from 10x10 to 50x50.

# \- Keyboard controls using arrow keys.

# \- Locked door that requires a key.

# \- Random key placement.

# \- Help menu with game instructions.

# 

# &#x09;Symbols:



# P - Player

# \# - Wall

# . - Empty space

# K - Key

# D - Locked door

# E - Exit

# 

# &#x09;Controls:



# Use the arrow keys on your keyboard to move:

# 

# ↑ - Move up

# ↓ - Move down

# ← - Move left

# → - Move right

# 

# &#x09;How to Play:



# 1\. Start the game.

# 2\. Choose a labyrinth size between 10 and 50.

# 3\. Find the key (K) in the upper half of the labyrinth.

# 4\. Reach the locked door (D). Collecting the key removes the door.

# 5\. Find your way to the exit (E) in the bottom-right corner.

# 

# &#x09;Requirements:



# \- C++ compiler.

# \- Windows operating system.

# \- Console that supports "conio.h" and "getch()".

# 

# &#x09;How to Run:



# 1\. Download or clone the repository.

# 2\. Open the project in a C++ IDE.

# 3\. Compile and run the program.
